WCAG 2.2 Accessibility Review — screens4.html

Audits the app screens only (dark + light). Re-reads the target file live on every run.

Scope & honesty note. This audit is scoped to the app screens only (every dark + light phone frame). The catalog's own header/titles, the per-frame caption tags, and the Design System & App Icon boards are intentionally excluded. It is an automated static + rendered-DOM audit: it reliably catches machine-detectable failures (missing names, labels, contrast, target size, structure). Criteria marked Manual require human review, and DOC criteria (language, viewport, focus CSS) are document-wide settings the screens inherit. A "Pass" means no automated failures were found — not full WCAG conformance.
