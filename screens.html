Setup · DB missing
9:41
Setup required

Database not configured

This app reads DATABASE_URL from .env.local. Copy the template and fill in the connection string from the WISEintelligence user secret.

cp .env.local.example .env.local

Next.js auto-reloads on .env.local changes — no dev-server restart needed. Press Retry once the file is in place.

Surfaced when DatabaseNotConfiguredError bubbles from the app layout. Mock mode silences this — DATABASE_URL must be unset AND PN_MOCK_DATA != 0.
Setup · DB unreachable
9:41
Database unreachable

Can't reach prod-db.example.com

DNS or network couldn't open a socket to the configured host. Common fixes:

  • Confirm DATABASE_URL in .env.local is the form postgresql://user:pass@host:5432/db.
  • If the database is behind a VPN, make sure you're connected.
  • For RDS / Aurora, verify the security group allows your current public IP.

Next.js auto-reloads on .env.local changes. Press Retry once you've fixed the connection string.

Variant when query() rewraps a libuv error as DatabaseUnreachableError. Hostname renders inline; placeholder hostnames trigger an extra "looks like the .env example" hint.
